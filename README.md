# Fútbol 7 de Álvaro

Aplicación web instalable con todos los partidos publicados del C.D. Fuenlabrada El Naranjo en la liga escolar alevín de Fuenlabrada, incluidos los anteriores y los que aún no tengan fecha u hora confirmada. Consulta los resultados publicados por el Ayuntamiento.

## Ejecutar

Desde esta carpeta:

```sh
python3 -m http.server 8000
```

Abre `http://localhost:8000` en el navegador. Para instalarla en otro dispositivo, publícala en una dirección HTTPS y utiliza la opción «Instalar aplicación» o «Añadir a pantalla de inicio» del navegador.

La aplicación necesita conexión para consultar y actualizar los partidos. Sin conexión puede abrirse la interfaz después de haberla visitado, pero no se guarda el calendario. El enlace al calendario oficial permite contrastar horarios y posibles cambios.
